A team advertising project involving audience research, competitor analysis, creative testing, landing-page optimization, audience targeting, and campaign performance analysis.

The optimized campaign increased average CTR from 0.79% to 1.69%, reached a peak CTR of 2.69%, generated more than 143,000 impressions, and acquired 254 new followers at RMB 12.12 per acquisition.

**Key Skills:** Audience Research, A/B Testing, Creative Optimization, Conversion Funnel Analysis, Campaign Analytics

A team data science project that used Python and machine learning to predict video game ratings. The project involved multi-source data collection, data cleaning, feature engineering, regression modeling, and performance evaluation.

The original project repository is maintained by a teammate. My individual contributions and the original team repository are documented on the project page.
